Для запуска скрипта:
<p>Поместить файлы логов в папку logs проекта
<p>Запустить скрипт без создания файла отчета:
<p>python main.py app1.log app3.log app2.log
<p>где app1.log app3.log app2.log - названия файлов логов (можно вводить любое количество)
<p>Запустить скрипт с созданием файла отчета:
<p>main.py app1.log app3.log app2.log --report handler.txt
<p>где параметр после --report: имя создаваемого файла
<p>файл отчета создается в папке output

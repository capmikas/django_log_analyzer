Для запуска скрипта:
<p>1. Поместить файлы логов в папку logs проекта
<p>2. Запустить скрипт без создания файла отчета:
<br>python main.py app1.log app3.log app2.log
<br>где app1.log app3.log app2.log: названия файлов логов (можно вводить любое количество)
<p>3. Запустить скрипт с созданием файла отчета:
<br>main.py app1.log app3.log app2.log --report handler.txt
<br>где параметр после --report: имя создаваемого файла
<p>Файл отчета создается в папке output
